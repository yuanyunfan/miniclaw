description: Generic Markdown report structure for cron task output contracts
kind: template
vars: [audience]
---
Use Markdown suitable for {{audience}} readers.

Required structure:

## Summary
Give the direct conclusion first.

## Key Findings
List the important observations, grouped by topic when helpful.

## Evidence
Include concrete data points, source names, timestamps, or uncertainty notes that support the findings.

## Next Actions
List only actionable follow-ups. Omit this section if there are no useful follow-ups.
